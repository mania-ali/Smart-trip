# Smart Trip Planner

A modern React-based web application that helps users plan trips by searching for countries or cities and viewing useful travel information in one place.

##  Features

-  Search by country or city
-  View country information
-  View city details using geocoding
-  Weather information
-  Save favorite destinations
-  Responsive user interface
-  Fast performance using React + Vite

---

##  Tech Stack

### Frontend
- React
- Vite
- React Router
- CSS / Tailwind CSS (whichever you're using)

### APIs
- Country API
- Geocoding API
- Weather API

##  Installation

Clone the repository

```bash
git clone https://github.com/mania-ali/Smart-trip.git
```

Go into the project

```bash
cd Smart-trip
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
